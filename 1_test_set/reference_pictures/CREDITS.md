# Credits of the reference pictures

These pictures are the **reference test set**: they are the same for
everybody, so the scores of different models (and of different people) can be
compared. They are given in their original size on purpose:
`1_test_set/make_test_set.py` brings them to 320x256, as it does with any
picture.

| File | Size | Subject | Author / source | License |
|---|---|---|---|---|
| `astronaut.png` | 512x512 | Astronaut Eileen Collins | NASA (NASA Great Images database), via the scikit-image sample data | public domain |
| `chelsea.png` | 451x300 | Chelsea the cat | Stefan van der Walt, via the scikit-image sample data | CC0 |
| `coffee.png` | 600x400 | Coffee cup (courtesy of Pikolo Espresso Bar) | Rachel Michetti, via the scikit-image sample data | CC0 |
| `hubble_deep_field.jpg` | 1000x872 | Hubble eXtreme Deep Field | NASA (HubbleSite), via the scikit-image sample data | public domain |
| `immunohistochemistry.png` | 512x512 | Immunohistochemical staining of colonic glands | Center for Microscopy And Molecular Imaging (CMMI), via the scikit-image sample data | no known copyright restrictions |
| `rocket.jpg` | 640x427 | Launch of DSCOVR on Falcon 9 | SpaceX, via the scikit-image sample data | public domain |
| `testcard.png` | 1280x1024 | Test card: colour bars, grey ramp, large and small text, thin lines | made for this package | CC0 |

The scikit-image sample data: https://scikit-image.org/docs/stable/api/skimage.data.html

The test card is the hardest picture of the set: thin lines and small text
are what a denoiser most easily blurs.
